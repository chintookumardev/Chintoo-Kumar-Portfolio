# Code of Conduct

## Our Commitment

I am committed to creating a welcoming, respectful, and inclusive environment for everyone who interacts with this project.

All contributors, visitors, and users are expected to communicate and collaborate respectfully.

## Expected Behavior

Examples of positive behavior include:

- Being respectful and considerate of others.
- Using welcoming and inclusive language.
- Providing constructive feedback.
- Respecting different opinions and perspectives.
- Focusing on the project and its technical goals.
- Accepting constructive criticism professionally.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Trolling or deliberately disruptive behavior.
- Publishing someone's private information without permission.
- Offensive or inappropriate comments.
- Intimidation, threats, or abusive language.
- Any other behavior that creates an unsafe or hostile environment.

## Reporting Issues

If you experience or observe unacceptable behavior, please report it by contacting:

**Email:** chintookumar.dev@gmail.com

Please provide enough information to help understand the situation, including relevant links, screenshots, or other context when appropriate.

Reports will be handled respectfully and as confidentially as reasonably possible.

## Project Participation

Contributors are expected to follow this Code of Conduct when submitting:

- Issues
- Pull requests
- Documentation
- Code
- Suggestions
- Discussions

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this Code of Conduct.

Serious or repeated violations may result in restrictions on participation in the project.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other project-related interactions.

## Acknowledgement

By participating in this project, you agree to follow this Code of Conduct and help maintain a respectful environment for everyone.
